## 🌿 Branching Strategy
* **`main`**: Production-ready code and stable releases only.
* **`dev`**: Integration branch where features are combined and tested before merging to `main`.
* **`feature/*`**: Isolated branches created for individual tasks, bug fixes, or documentation.
